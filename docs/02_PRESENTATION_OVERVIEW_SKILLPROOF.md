# 02 — IDEA & SIMPLE FLOW — SKILLPROOF

## Idea

**SkillProof** is an AI-powered platform that helps students understand where they currently stand compared with their target career, identify the skills they are missing, and receive a personalized roadmap plus a real-world project to improve and prove those skills.

### Problem
Students often follow the university curriculum but do not clearly know:
- what additional skills their target career actually requires,
- what their current skill level is,
- what they should learn next,
- and how to prove those skills to employers.

### Solution
SkillProof uses AI to:

```text
Assess
→ Identify Skill Gaps
→ Recommend Learning Roadmap
→ Practice
→ Build Real-World Project
→ Prove Skills
```

### Core Value
> From skill gaps to career proof.


### Assessment Approach
The assessment is designed as a **career-readiness test**, using interview-style questions and practical cases that reflect real job expectations.

Instead of testing only academic knowledge, SkillProof evaluates:
- how students explain concepts,
- how they solve realistic problems,
- how they reason through job-related scenarios,
- and how prepared they are for future interviews.

For the prototype, questions are manually curated. Any question claimed to come from a real company interview must have a verifiable source; otherwise it should be marked **[source not verified - unverified]**.

## Simple Flow

```text
1. Choose Target Role
        ↓
2. Complete Career Readiness Test
   - Interview-style questions
   - Practical cases
   - Reasoning questions
        ↓
3. AI Builds Current Skill Profile
        ↓
4. Identify Skill Gaps
        ↓
5. Generate Personalized Roadmap
        ↓
6. Recommend Real-World Project
        ↓
7. Build Project & Create Career Evidence
```

---

## Example

```text
Target Role:
Backend Developer

Diagnostic Result:
REST API       Intermediate
SQL            Beginner
Testing        Beginner
System Design  Beginner

Skill Gaps:
SQL
Testing
System Design

Roadmap:
SQL → Testing → System Design

Recommended Project:
Expense Management API

Project Requirements:
- Relational database
- Meaningful SQL queries
- Unit tests
- Validation
- Basic system design

Outcome:
A project that directly proves the skills the student was missing.
```

---

## Main Message

SkillProof does not only tell students what they should learn.

It helps them:

> **understand what they are missing → learn the right skills → build a project based on those gaps → turn the result into career evidence.**
