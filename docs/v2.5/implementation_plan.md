# Implementation Plan: SkillProof V2.5 — Curated Learning Resources + Project Catalog

Extend the V2.4 personalized canonical roadmap with verified learning resources and curated projects, strictly adhering to zero-invented-URL and zero-OpenAI policies for catalog candidate selection.

## User Review Required

> [!IMPORTANT]
> **Authoritative Determinism & Zero AI Invention:**
> 1. Learning resources are mapped strictly to canonical skill IDs from `data/v3/canonical-skills.json`. No URLs or courses are generated by LLMs.
> 2. YouTube resources are completely omitted to ensure 100% inspectable, authoritative provenance without video link hallucination.
> 3. Projects are curated from `practical-tutorials/project-based-learning` (commit `fcd321e`) for software roles and grounded `skillproof-curated` specifications for Data Analyst (where `project-based-learning` lacks coverage).
> 4. Project candidate selection uses deterministic qualitative ordering based on trusted server-side session gaps and roadmap node states. No numeric match percentages (e.g. no "87% match") are exposed.
> 5. Deep Learning remains an optional elective for Data Analyst, not a core requirement.
> 6. Existing project submission and evaluation flows (`/portfolio`) are strictly preserved. V2.6 GitHub/Web deep evaluation is NOT implemented in this milestone.

## Proposed Changes

### 1. Data V3 Catalog Artifacts

#### [NEW] [learning-resources.json](file:///d:/Roy/SkillProof-Support-AI/data/v3/learning-resources.json)
Curated collection of verified resources for canonical skills across Frontend, Backend, and Data Analyst roles.
- Official documentation (MDN, WHATWG, PostgreSQL, Python, Pandas, dotnet, etc.)
- Resource types: `official-doc`, `guide`, `tutorial`, `interactive-practice`, `reference`
- Qualitative levels: `foundation`, `applied`, `advanced`
- Strict fields: `id`, `title`, `sourceName`, `sourceUrl`, `resourceType`, `canonicalSkillIds`, `roleIds`, `level`, `isOfficial`, `verificationStatus`, `verifiedAt`, `locator`

#### [NEW] [projects.json](file:///d:/Roy/SkillProof-Support-AI/data/v3/projects.json)
Curated collection of practice and portfolio projects.
- Practice projects: targeted, 1-3 roadmap nodes (e.g. Vanilla JS Weather App, Todo App, SQLite B-Tree engine)
- Portfolio projects: comprehensive, multi-competency evidence artifacts (e.g. Fullstack Redux/React Voting System, Resilient Inventory & Order Service, End-to-End Retail EDA & BI Dashboard)
- Data Analyst projects labeled honestly with `provenance: "skillproof-curated"`
- Strict fields: `id`, `title`, `source`, `sourceUrl`, `sourceLocator`, `provenance`, `roleIds`, `canonicalSkillIds`, `roadmapTargets`, `projectType`, `difficulty`, `estimatedScope`, `description`, `deliverables`, `evidenceRequirements`, `verificationStatus`, `verifiedAt`
